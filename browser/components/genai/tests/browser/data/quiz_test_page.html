Quiz Assist — Test Page

Use the keyboard shortcuts below to test the native Firefox AI quiz assistant.

Alt+AAnalyze the current question and get an AI answer
Alt+SToggle the answer overlay on/off
Alt+Shift (hold)Temporarily reveal the dimmed overlay
Alt+DDismiss / close the answer overlay
Alt+Shift+HOpen the answer history sidebar
API Key Setup: Open about:config and set browser.quizAssist.apiProvider to openai, gemini, or anthropic, then set browser.quizAssist.apiKey to your key. Without a key the question is forwarded to the GenAI chat sidebar. Set browser.quizAssist.autoFill to true to enable automatic form filling.
